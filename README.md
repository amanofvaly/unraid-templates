# Crowbarr Unraid templates

Community Applications templates for [Crowbarr](https://github.com/amanofvaly/crowbarr).

- `templates/crowbarr.xml`: CPU image
- `templates/crowbarr-cuda.xml`: NVIDIA image, needs the Nvidia Driver plugin

Install from the Apps tab. To use before the Community Applications listing is live, open
Docker, Add Container, Template repositories, and add
`https://github.com/amanofvaly/unraid-templates`.

See [docs/unraid.md](https://github.com/amanofvaly/crowbarr/blob/main/docs/unraid.md) for setup.
